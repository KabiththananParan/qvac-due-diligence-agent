# QVAC Due Diligence Agent - Data Model

## Purpose

This document defines the information that flows through the system.

The goal is to establish a common structure for:

* Uploaded documents
* Startup information
* Agent outputs
* Final reports

This data model serves as the foundation for all future backend, agent, and frontend development.

---

# System Data Flow

Uploaded Documents
↓
Document Extraction
↓
Startup Profile
↓
Agent Analysis
↓
Final Report

---

# 1. Document Model

## Purpose

Represents a file uploaded by the user.

---

## Fields

### Document ID

Unique identifier for a document.

---

### File Name

Original uploaded filename.

Examples:

* pitch-deck.pdf
* financials.pdf
* whitepaper.pdf

---

### File Type

Supported values:

* PDF

Future:

* PPTX
* DOCX

---

### File Size

Size of uploaded file.

---

### Upload Timestamp

Date and time of upload.

---

### Extraction Status

Possible values:

* Pending
* Processing
* Completed
* Failed

---

### Extracted Text

Text content extracted from the document.

Used by AI agents during analysis.

---

# 3. Agent Result Model

## Purpose

Defines a common output structure used by all analysis agents.

This allows all agent results to be displayed consistently.

---

## Agent Information

### Agent Name

Examples:

* Market Analyst
* Team Analyst
* Risk Analyst
* Financial Analyst

---

### Analysis Status

Possible values:

* Pending
* Running
* Completed
* Failed

---

## Evaluation Metrics

### Score

Numerical value between:

0 - 100

---

### Strengths

Positive findings identified by the agent.

Examples:

* Large market opportunity
* Experienced founding team
* Clear revenue model

---

### Weaknesses

Negative findings identified by the agent.

Examples:

* Limited traction
* High competition
* Regulatory uncertainty

---

### Evidence

Facts or information supporting the analysis.

Examples:

* Market statistics
* Team credentials
* Financial assumptions

---

### Insights

Agent-specific reasoning and observations.

Provides detailed explanation behind the score.

---

### Confidence Level

Agent confidence percentage.

Range:

0 - 100

---

# MVP Data Requirements

Version 1 requires:

* Document Model
* Startup Profile
* Market Analysis Result
* Team Analysis Result
* Risk Analysis Result
* Financial Analysis Result
* Investment Recommendation
* Final Report

No database design is required at this stage.

The focus is defining the information that moves through the system.

---

# Success Criteria

Every AI agent should receive structured startup information and return a consistent analysis format.

The final report should be generated by combining all agent outputs into a transparent and explainable investment recommendation.
