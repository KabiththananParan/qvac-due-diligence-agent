# Screen 2 - Upload

## Purpose

Allow users to upload startup documents for analysis.

---

## Components

### Upload Area

Drag and Drop Zone

Supported Files:

* PDF

Maximum Files:

* 5

### Uploaded Documents List

Displays:

* File Name
* File Size
* Upload Status

Example:

* pitch-deck.pdf
* financials.pdf
* whitepaper.pdf

### Validation Messages

Examples:

* Unsupported file type
* Maximum file limit exceeded
* Upload failed

### Action Button

Start Analysis

---

## Actions

### Upload Documents

User uploads one or more PDF files.

### Remove Document

User removes uploaded file before analysis.

### Start Analysis

Enabled only when at least one document is uploaded.

If no documents exist:

Start Analysis button remains disabled.

# MVP Success Criteria

A user can:

1. Upload up to 5 startup documents.
2. Observe agent-by-agent analysis progress.
3. Review transparent agent evaluations.
4. Receive a numerical investment score.
5. Receive a final recommendation.
6. Understand the reasoning behind every score.
